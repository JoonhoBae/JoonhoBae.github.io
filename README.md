# Joonho Bae — Academic Website

A lightweight, one-page academic website prepared for GitHub Pages and the custom domain `joonhobae.com`.

## Publish on GitHub Pages

1. Create a public repository named `JoonhoBae.github.io`.
2. Upload every file and folder in this directory to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. After `https://joonhobae.github.io` works, connect `joonhobae.com` in GitHub Pages and update its DNS records at Cloudflare.

The included `CNAME` file already identifies `joonhobae.com` as the custom domain.

## Update the site

- Main text, papers, and teaching: edit `index.html`.
- Colors and layout: edit `assets/styles.css`.
- Profile photo: replace `assets/joonho-bae.jpg` using the same filename.
- CV: replace `assets/Joonho_Bae_CV.pdf` using the same filename.

No build process or paid hosting is required.
